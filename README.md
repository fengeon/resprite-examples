# resprite-examples
Example projects and demo files for Resprite.

## Examples

- [Isometric Village Tilemap](tilemap/260928_xilurus_iso_village/) — A tiny isometric pixel world built with Tilemap Layers in Resprite, using Xilurus's village tileset.
- [Ninja Adventure Rectangular Tilemap](tilemap/260924_ninja_adv_rect_tilemap/) — A desert pixel scene built with rectangular Tilemap Layers in Resprite, using the Ninja Adventure asset pack.
