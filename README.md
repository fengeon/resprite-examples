# resprite-examples
Example projects and demo files for Resprite.

## Examples

- [Isometric Village Tilemap](tilemap/260928_xilurus_iso_village/) — A tiny isometric pixel world built with Tilemap Layers in Resprite, using Xilurus's village tileset.
- [Ninja Adventure Rectangular Tilemap](tilemap/260924_ninja_adv_rect_tilemap/) — A desert pixel scene built with rectangular Tilemap Layers in Resprite, using the Ninja Adventure asset pack.
- [Rect Room Tiles](tilemap/260806_rect_room_tiles/) — A room scene built from multiple tilesets, with editable source artwork and a Tiled export.
- [Tiny Isometric Scene](tilemap/260807_tiny_isometric_scene/) — A layered isometric scene with an editable tileset, a Resprite tileset package, and a Tiled export.
- [Summer Land Dual-grid Terrain](tilemap/260813_summer_land_dual_grid_terrain/) — A 16-tile dual-grid tileset demonstrating terrain rules, with a Resprite tileset package and a Tiled export.
